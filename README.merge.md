# Aevara (full UI shell, no Firestore)
- Drop `lib/`, `assets/`, and `pubspec.yaml` into your `aevara_master/` repo.
- `flutter pub get` → `flutter run`.
- Dev Navigator (bug FAB) in debug builds to jump anywhere.
- Replace `features/home/home_placeholder_page.dart` with your live dashboard.
- All screens, sheets, and interactions are wired with placeholder actions (no data layer).
